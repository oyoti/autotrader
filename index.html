Strategy settings

The bot watches for a digit repeating back-to-back the set number of times. When that happens, and the temperature filter is on, it checks the digit's count across the analysis window — if that digit is currently the most frequent or the least frequent (among digits that have appeared), it skips the trade; otherwise (or with the filter off) it buys a Differs contract barriered on that digit, betting the streak breaks. With the filter off, every qualifying repeat is traded regardless of how hot or cold that digit currently is. Each symbol trades one contract at a time and pauses for the cooldown after a result. Martingale, if set above 1, multiplies a symbol's next stake after a loss and resets it to the base stake after a win — each symbol tracks its own stake independently. Take profit, if set, automatically stops trading once net session P/L reaches that value.
